# Supermarket Sales Exploratory Data Analysis

## Overview
Exploratory analysis of supermarket transaction data using Python. The notebook examines transaction-level fields and uses charts to explore relationships among product lines, unit prices, customer ratings, payment methods, city, and gross income.

## Objectives
- Inspect and prepare supermarket transaction data.
- Explore product-line and customer-related patterns.
- Visualize distributions and relationships in the data.
- Investigate time-based gross-income patterns by city.

## Tools
Python, Pandas, Matplotlib, Seaborn, Plotly, Jupyter Notebook.

## Repository structure
- `notebooks/supermarket_sales_analysis.ipynb` — exploratory analysis and visualizations.
- `data/` — place the dataset here only if redistribution is permitted.

## Run locally
1. Install Python 3.10+ and Jupyter.
2. Install dependencies: `pip install -r requirements.txt`
3. Put the permitted dataset at `data/supermarket_sales.csv`.
4. Open the notebook and update the CSV path to `data/supermarket_sales.csv` if needed.
5. Run the cells from top to bottom.
